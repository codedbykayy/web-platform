A component is a self-contained feature that can be dropped into any website regardless of the business' brand.
Every component owns 4 things:
1. Structure
2. Behavior
3. Default appearance
4. Documentation
The specific website brand then owns these 5 things:
1. Content
2. Branding
3. Layout
4. Assets
5. Which components are used
A component should never need to know what business it's on.
Never mix reusable logic with client specific behavior.
